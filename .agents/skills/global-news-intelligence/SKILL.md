# Global News Intelligence

## 目标与覆盖
生成可追溯来源的简体中文全球新闻简报。全球覆盖，重点关注美国、中国、俄罗斯、欧洲（欧盟、英国、法国、德国）和中东（伊朗、以色列、巴勒斯坦、沙特、土耳其），并补充亚洲其他地区、非洲、拉美和大洋洲的重要事件。

## 时间窗口
- 早间版：北京时间前一日 19:00 至当日 07:00。
- 晚间版：北京时间当日 07:00 至 21:00。
- 分别记录事件发生时间和媒体发布时间；不得混为一谈。
- 时间不明确时注明精度，不猜测具体小时。

## 采集与聚类
1. 使用 `config/sources.yaml` 中的 RSS 来源。
2. 使用 GDELT 等全球新闻索引补充发现；索引结果只是线索，不是事实核验。
3. 按事件聚类，不按媒体简单堆叠；保留各来源原始标题、媒体名称、发布时间、链接和摘要。
4. 对重要事件尽量寻找至少三个相互独立、来自不同国家或地区的来源；不足时明确说明。
5. 去重时保留来源多样性，不要误合并不同事件。

## 证据标准
明确区分多来源确认事实、官方声明、单一媒体报道、当事方指控、未经证实信息、分析推测。不得根据媒体国籍臆断政治立场。比较事实选择、措辞、引用对象、遗漏信息和叙事框架，并给出来源证据。官方声明不自动等于独立核实。

军事行动、伤亡、领土控制、选举结果和经济数字必须注明来源与数据时间。存在冲突时并列呈现，不擅自裁决。

## 深度分析
对重大事件分析背景与时间线、已确认事实和争议、参与方公开立场、利益与约束、区域安全/国际关系/贸易/能源/金融影响，以及未来24–72小时观察指标。预测必须标注为分析判断并说明不确定性。

## 报告结构
1. 全球要闻速览；
2. 重点地区动态；
3. 跨国媒体视角对比；
4. 深度分析；
5. 未来24–72小时观察清单；
6. 来源链接与核验说明。

## 输出规范
简体中文，保留媒体原名和原始标题。每条重要新闻附可打开的原始来源链接。无法访问原文时注明“仅依据 RSS 摘要/搜索摘要”。宁缺毋滥，不编造来源、链接、引文、数字或媒体观点。若本时段没有足够证据支持重大新进展，应如实说明，不用旧闻填充。
